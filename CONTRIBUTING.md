# Contributing

## Commits

[Conventional Commits](https://www.conventionalcommits.org), subject only:

```
<type>(<scope>): <what changed>
```

`scope` is the command or module touched: `submit`, `view`, `client`, `nix`.
Imperative, no trailing period, 72 characters or fewer. No body. A commit that
needs more explanation than that is two commits.
